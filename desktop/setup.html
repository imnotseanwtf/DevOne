Choose DevOne's database

DevOne keeps your projects, issues, drawings and settings in a PostgreSQL database.

Connection

The password is stored encrypted with your system's keychain, not in a settings file. The database must already exist; DevOne creates its tables in it.

Encryption key

DevOne encrypts saved tokens and passwords with a key. Everyone sharing a database must use the same key: the person who set the database up copies theirs, the others paste it here.

Replacing the key makes tokens saved with the old one unreadable, so copy it first if you might need it.
